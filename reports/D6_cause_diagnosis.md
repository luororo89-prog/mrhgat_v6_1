# S2、50%强度未满足识别条件的原因核查

## 结论

直接原因是补偿信号被分配到名为“竞争”的通道，导致按固定通道身份计算的补偿识别指标降低。固定模拟数据和训练轮数、只更换模型初始化即可复现差异，支持随机初始化敏感及通道语义不稳定的判断。现有证据不支持通过修改原始输入或降低0.85阈值解决问题。

本次只核查 none 配置、S2、50%强度的主要异常。未重做其他配置的完整验收，也未开展真实数据机制分解。

## 1. 保存结果可复现

五份模拟数据及 expected 真值均从原始生成规则精确重建，与保存数组逐项一致。重新载入五个模型后，补偿边、节点AUC均与原结果一致。后验数值有限，三个通道份额之和与1的最大误差约为5.96×10⁻⁷。

种子3保存模型的结果：

| 指标 | 数值 |
|---|---:|
| 用补偿通道识别真实补偿边的AUC | 0.187981 |
| 用竞争通道识别同一组真实补偿边的AUC | 0.989125 |
| 补偿通道识别低供给起点的AUC | 0.009683 |
| 竞争通道识别低供给起点的AUC | 0.958783 |
| 低供给起点的平均补偿通道份额 | 2.23% |
| 低供给起点的平均竞争通道份额 | 49.64% |

这些份额为有流出低供给起点的节点等权均值。用于生成该情景的低供给起点补偿混合比例为50%。竞争通道对补偿信号的高识别度仅用于定位信号去向，不能替换正式补偿AUC，也不能据此直接交换通道标签。该保存模型的竞争通道同时还识别了竞争边，竞争边AUC为0.952227，因此存在通道混合，不是已证明的完整一一交换。

## 2. 固定数据的交叉对照

独立设置数据种子与模型初始化种子，保持原模型、学习率、正则化、输入和每份数据的基准初始化一致，均训练108轮。合成真值只用于诊断评分，不用于训练或选择结果。

| 数据种子 | 模型初始化种子 | 补偿边AUC | 补偿节点AUC | 总流向交叉熵（越低越好） |
|---:|---:|---:|---:|---:|
| 0 | 0 | 0.990785 | 1.000000 | 6.136760 |
| 0 | 3 | 0.096278 | 0.000627 | 6.134639 |
| 3 | 0 | 0.991629 | 1.000000 | 6.135172 |
| 3 | 3 | 0.187981 | 0.009683 | 6.136435 |

两份数据上都出现随初始化变化的通道混淆。数据种子3在初始化0下能恢复补偿识别；数据种子0在初始化3下也出现明显混淆。因此该差异不能仅归因于种子3的模拟抽样。数据种子0中，补偿识别很低的模型甚至具有略低的总流向交叉熵，说明总流向拟合指标不足以识别这种通道语义问题。

## 3. 延长训练的对照

固定数据种子3、模型种子3，连续训练至400轮：

| 轮数 | 补偿边AUC | 补偿节点AUC | 总流向交叉熵 |
|---:|---:|---:|---:|
| 108 | 0.187981 | 0.009683 | 6.136435 |
| 200 | 0.240379 | 0.057314 | 6.138583 |
| 400 | 0.219670 | 0.028458 | 6.130846 |

该对照没有显示延长训练能恢复通道语义。不能据此声称所有训练设置均无效，但可排除“该运行只需训练到现有400轮上限即可解决”的解释。

## 4. 与模型目标的对应关系

代码中损失是总去向概率的交叉熵加矩阵正则项；总去向概率由各通道混合得到。它没有直接监督哪部分总流量必须属于补偿或竞争。

补偿和竞争的目的地注意力采用同类结构，两者都只排除本地目的地，没有将向高供给或平级/低供给流动规定为通道约束。两者门控来源虽不同，但参数也未限定其方向。因此结构差异没有在这些对照中稳定固定通道的机制含义。

这与方案第237行“预期不写进模型”、第80行禁止将Δ等事后量写入输入或损失的设定有关。不能为提高AUC直接塞入机制真值或供给差方向，再把恢复结果当作独立验证。当前结果支持存在机制辨识不足，但不构成对整个模型不可辨识的数学证明。

## 5. 另需记录的实现差异

模拟验收执行脚本使用 `masks(sim, 0)` 的一个留出折决定训练轮数；方案第303—304行规定五个空间折、取最佳轮数中位数。当前模拟轮数选择未完整落实这项规定，正式完整验收需要处理。本次固定108轮的交叉对照已经显示通道混淆，所以不能把它全部归因于留出折的选择。此次核查未修改训练流程。

## 6. 后续处理边界

优先解决通道是否能够稳定对应机制的模型识别问题，确定不使用待检验真值的识别依据，再开展独立模拟验收。多次初始化只能帮助暴露这种不稳定；仅选择高AUC种子、按模拟真值改标签或降低阈值不能完成验证。若调整模型识别约束，应明确更新方法设定并重新验证。

当前没有据此要求重做输入数据的证据；原始九项设施评价、总人流、拓扑、无时间及无容量校正口径保持原样。
