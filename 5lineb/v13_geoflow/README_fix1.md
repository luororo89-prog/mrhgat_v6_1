# OD 点对路由的独立层映射版本

本配置启用第 1 点修改 `fix1`。五层路由各自使用点对映射，每层迭代 7 次。第 1 层与预测头共用原有映射，第 2 至 5 层的映射独立训练，初始值均为半单位矩阵。

目的地预测继续使用原有的路由概率加权点对相似性，以及压力、拓扑和距离项。注意力聚合保持原样。损失为目的地交叉熵加 Adam 耦合 L2 正则。未增加残差、通道均衡或跨种子一致性目标。

## 运行

在仓库根目录执行

```bash
python 5lineb/v13_geoflow/run_od_ablation_v13.py --config 5lineb/v13_geoflow/configs/redo_d0.25_od_ablation_v13.yaml
```

配置中的 `variants: [fix1]` 仅运行所选版本，种子为 0、1、2。现有 `run_v13.py` 的配置和行为保持原样。新增的 `run_od_relation_v13.py` 提供本版本使用的共同训练与评估函数。

输入使用 d=0.25 网络和固定供给标尺，路径已在配置中给出。结果目录为 `results_od_ablation/redo_d0.25_od_ablation_v13`。

## 已有结果

平均 CPC 为 0.5647，主导硬通道平均流量占比为 66.12%，通道对齐后的跨种子概率相关性为 0.2091。相关性是诊断指标。C1 和 C2 尚不是经过机制验证的标签。

预测指标针对固定留出的外流目的地。CPC 和 NRMSE 使用已知的留出起点总量，不代表独立预测绝对流量。

仓库保存三个种子的指标、训练历史、日志及汇总诊断。大型权重、预测数组和逐边结果保存在已交付的 `od_four_way_ablation_model_and_results.zip`。直接运行训练命令会在缺少权重或预测数组时重新训练。
