# v13 主模型思路 Base–Compensation–Competition 网络

## 一 主模型的设定 三条机制通道

节点是 666 个社区，特征 x 是九项供给指标。边是社区间的就医出流人次。主模型的目标是把每一条社区间出流边软分配到两条匿名通道上，训练结束后通过事后检验命名为补偿通道和竞争通道，社区内部出行单独作为 Base 自持机制。

## 二 第一步 自身供给嵌入 技术自环

每个社区先把九项供给指标投影成通道向量，z_A,k = LeakyReLU(W_k^T (ω_k ⊙ x_A) + b_k)，每个通道 k 有自己的权重和偏置，逐元素缩放系数 ω 也是可学习的，相当于每个通道用不同的视角读供给。然后做单位化 zr = z/‖z‖。这一步叫技术自环，保证每个社区始终位于自己的路由中心，权重为 1，与真实的内部出行份额分开记录，真实的内部份额在第四步才加权进来。

## 三 第二步 流入压力 只读不改邻居供给

对每个设施层级，计算外来流入与本地可达服务量之比的对数，即 P_A,l = log1p(I_A / RA_A,l)，其中 I_A 是其他社区流向 A 的总人次。只在拥有该层服务的社区内做标准化，没有该层服务的社区压力取零，同时拼接三个层级的有无服务指示，共六维。压力通过一个从零初始化的线性变换 V 加到社区自身向量上，zo_A,k = l2(z_A,k + V_k^T f_A)。压力只改变 A 自己的表示，流入邻域的供给永远不会被聚合进 A，这是主模型和普通图卷积的重要区别。

## 四 第三步 软路由 把每条出流边分给两条通道

这是主模型的核心，来自 DisenGCN 的软路由机制。对每条边 A 到 B，通道分配概率是目的地通道向量与出发社区路由中心的相似度经温度缩放后的 softmax，p_AB,k = softmax_k(zr_B,k · c_A,k / τ)。路由中心 c_A,k 在迭代中更新，初始就是 zo_A,k，每一步用出行份额加权的邻居通道向量回填，c_A,k ← l2(zo_A,k + Σ_B π_AB p_AB,k zr_B,k)，迭代 5 次。这是一个自洽的过程，每条边属于哪个通道，由目的地向量和路由中心相互磨合决定。分配概率之和为 1，所以一条边可以同时带两种机制，这是软分配，不是非此即彼。

## 五 第四步 通道内注意力 目的地加权聚合

在每个通道内部，对 A 的目的地再做一次注意力加权。注意力系数 α_AB,k 由通道专属参数 a_k 对出发和目的向量打分，加上流量权重的对数项 log(π_AB p_AB,k) 后做 softmax，初值为零，初始状态退化为纯流量加权。社区的新表示 h_A,k = l2(π_AA zr_A,k + m_A,k Σ_B α_AB,k zr_B,k)，自持项用真实内部出行份额 π_AA 加权，出流项用该通道的出流份额 m_A,k 加权，其中 m_A,k = Σ_B π_AB p_AB,k。注意力系数只是聚合权重，不表示服务容量份额。

## 六 训练目标 目的地预测辅助任务

主模型不直接监督拆分比例，而是用目的地预测做辅助任务。评分 score_AB = Σ_k zr_B,k · h_A,k / τ_s + x_B · w_m − β t_AB + B0[topology_AB]，即通道相似度加上目的地供给偏好、距离惩罚和拓扑偏移，对目的地做 softmax。每个 epoch 随机取一半出流边传递消息，另一半和自环作为预测目标，损失是交叉熵，加上分通道的供给重构均方误差和权重衰减。锚点边弱标签可选加入，以流量加权交叉熵约束软分配方向。训练时两条通道保持匿名，通道编号不代表机制结论。

## 七 评估与机制命名

留出固定份额的出流边完全不参与训练，评估留出交叉熵、正确预测出行份额 CPC、NRMSE 和内部份额误差。消融覆盖单通道、关闭出流、关闭自持、关闭注意力、关闭压力五种设置。机制命名在训练后做，由补偿检验和竞争检验确定哪条通道是补偿、哪条是竞争，检验不过的通道不命名。
