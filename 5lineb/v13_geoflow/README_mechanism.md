# 非互斥机制路由与目的地预测联动模型（M1 与 M2）

依据 `博后三胎/DisenGAT_OD_routing_execution_plan.md` 实施。输入换为门诊 OD 版本，主体代码为新增文件，原有实现与结果未改动。

## 输入

`重做实验/step4_v13_input_outpatient` 由同目录 `flow_topology.py` 与 `build_v13_inputs.py` 生成，两个脚本复制自 time_filtered 版本，只改输入输出路径。OD、设施吸引力与供给取 `重做实验/step3_od_demand_outpatient/results`，标尺取其中 `node_typing/ruler.json`，等时圈取 worktree 中 `input_sources` 的同名文件。d=0.25 网络共 1,530,839 人次，流量阈值 2，保留 126,108 条社区间边，测试边 25,316 条，验证边 10,059 条。

## 模型

`model_od_mechanism_v13.py` 中的 `MechanismNet`。

1. 本地基线通道读取供给 embedding 与上下文中的社区内部人次、可见外流人次，不聚合邻居。
2. 节点层补偿倾向与竞争倾向各用一个独立 sigmoid，输入为供给、上述两项流量与流入压力。
3. OD 层两个机制门各用一个独立的单隐层网络加 sigmoid，输入为对应的节点倾向、起止供给、该边可见人次、道路阻抗、拓扑和起点压力。两个门之间没有 softmax，同一条 OD 可以同时进入两个通道。
4. 两个外部通道各有一套 GATv2 注意力与通道映射，在起点的可见外流邻居内归一化。补偿通道聚合目的地供给，竞争通道聚合目的地供给、阻抗和拓扑。被遮蔽的边不参与消息、注意力分母和压力。
5. 节点表示为三个通道拼接，预测头读取起止两端的三通道表示、起止供给、阻抗与拓扑，候选集与损失沿用 `run_od_relation_v13.train_one`。
6. M2 在训练时另取一个随机消息视图，损失加上两视图共有边上双门向量差的平方均值，预测损失只取第一视图。

损失只有目的地交叉熵与 Adam 耦合 L2，M2 另加一致性项。没有通道均衡、正交、互斥或人工标签。

社区内部人次进入本地通道与节点倾向，训练目标沿用原定义并保留社区内部选项。测试与验证指标只计算社区间去向，不受影响。

## 运行

```bash
python 5lineb/v13_geoflow/run_od_ablation_v13.py --config 5lineb/v13_geoflow/configs/outpatient_d0.25_od_ablation_v13.yaml
python 5lineb/v13_geoflow/run_od_mechanism_v13.py --config 5lineb/v13_geoflow/configs/outpatient_d0.25_od_mechanism_v13.yaml
python 5lineb/v13_geoflow/run_od_mechanism_v13.py --config 5lineb/v13_geoflow/configs/outpatient_d0.25_od_mechanism_stable10_v13.yaml
python 5lineb/v13_geoflow/benchmark_gravity_mechanism_v13.py --config 5lineb/v13_geoflow/configs/outpatient_d0.25_od_mechanism_v13.yaml
python -m pytest 5lineb/v13_geoflow/tests
```

结果分别在 `results_od_ablation/outpatient_d0.25_od_ablation_v13` 与 `results_od_mechanism/<配置名>`。每个种子保存配置、检查点、训练曲线、测试指标与逐边门值，汇总脚本对每个检查点重放测试分数并逐位核对。

## 结果（种子 0、1、2）

### 目的地预测

| 模型 | 测试 CE | CPC | NRMSE |
|---|---:|---:|---:|
| M0 fix1（5 层互斥路由，OD 点对头） | 4.191 ± 0.120 | 0.557 ± 0.036 | 6.36 |
| M1 完整三通道 | 3.812 ± 0.015 | 0.686 ± 0.002 | 4.09 |
| M2 一致性权重 1 | 3.808 ± 0.008 | 0.684 ± 0.005 | 4.20 |
| M2 一致性权重 10 | 3.796 ± 0.020 | 0.688 ± 0.008 | 4.09 |
| M2 一致性权重 100 | 3.820 ± 0.007 | 0.684 ± 0.004 | 4.11 |

M1 与 M0 同时改变了路由、聚合与预测头，提升不能单独归因于非互斥路由。

### 聚合贡献（M3）

| 设置 | 测试 CE | CPC | NRMSE |
|---|---:|---:|---:|
| 完整三通道 | 3.812 | 0.686 | 4.09 |
| 同一检查点外部通道置零 | 4.798 | 0.406 | 6.80 |
| 仅本地基线（重新训练） | 4.068 | 0.608 | 4.73 |
| 本地基线加补偿通道（重新训练） | 3.821 | 0.682 | 4.14 |
| 本地基线加竞争通道（重新训练） | 3.808 | 0.684 | 4.12 |
| 关闭供给点对直接路径（重新训练） | 3.798 | 0.693 | 4.06 |

三个种子上完整模型都优于仅本地基线。保留任一外部通道即可得到几乎全部增益，两个外部通道在预测上大部分重叠。供给点对直接路径不是预测所必需。

### 路由稳定性（测试上下文中非测试观测边，通道对应关系按训练边确定）

| 模型 | 补偿门跨种子相关（均值，最小） | 竞争门跨种子相关（均值，最小） | 双门向量平均绝对差 | 主导门一致率 | 节点倾向相关（补偿，竞争） |
|---|---|---|---:|---:|---|
| M0 fix1 路由份额 | 0.33（0.13） | 同左 | 0.27 | 0.41 | 无 |
| M1 | 0.28（−0.65） | 0.28（−0.80） | 0.19 | 0.61 | 0.35，0.32 |
| M2 权重 1 | 0.73（0.72） | −0.09（−0.61） | 0.21 | 0.70 | 0.18，−0.31 |
| M2 权重 10 | 0.66（0.60） | −0.01（−0.52） | 0.19 | 0.78 | 0.74，−0.29 |
| M2 权重 100 | −0.01（−0.32） | 0.38（−0.01） | 0.26 | 0.40 | 0.61，0.66 |

M1 中种子 1 与种子 2 的两个门相关为 0.84 与 0.95，种子 0 的竞争门与另两个种子方向相反，置换无法对齐。M2 权重 1 与 10 使补偿门在三个种子间一致，竞争门的方向分歧仍在。权重 100 使稳定性变差。

M1 双门同时大于 0.5 的流量占比为 0.7% 至 6.7%，门的平均二元熵为 0.69 至 0.79 比特，补偿与竞争通道向量的平均余弦为 −0.15 至 0.21，竞争通道注意力接近均匀。

### 重力模型对照（M4，诊断）

| 吸引力输入 | 测试 CE | CPC | NRMSE |
|---|---:|---:|---:|
| 仅距离与拓扑 | 5.330 | 0.226 | 9.22 |
| 九项供给 | 5.271 | 0.235 | 9.09 |
| M1 三通道表示 | 4.022 ± 0.034 | 0.602 ± 0.014 | 5.60 |

三通道表示含有可推广到留出边的目的地信息。该结果不作为机制正确性的证据。

## 尚未解决

1. 竞争门在不同种子间存在方向相反的两种解，视图一致性不能消除。需要更多种子估计两种解的出现频率，必要时再单独设计跨种子联合训练实验。
2. 两个外部通道在预测上大部分重叠，通道的机制含义需要按压力规则另行检验后再命名。
3. 社区内部人次作为输入时，训练目标中的社区内部选项部分可见。
