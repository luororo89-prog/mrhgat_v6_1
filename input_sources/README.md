# MR-HGAT input sources

This directory contains the 74 source files listed in the Stage A input
manifest. Paths below this directory preserve their original paths relative
to the local source root. No source file was edited or regenerated.

The source SHA-256 values are recorded in `source_sha256.json`. The
repository's Stage A code is unchanged and retains its configured source
path. This directory mirrors the source paths relative to that root.
Files used only for source comparison remain separate from the nine supply
evaluations, community flow and Queen topology used by the aggregate model.
